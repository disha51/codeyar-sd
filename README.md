# codeyar-sd
کد یار سحر دیناروند لینک وب‌اپلیکیشن آنلاین نیست. امکانات نسخهٔ آفلاین - نمایش رابط فارسی و سازگار با صفحهٔ موبایل - دسترسی آفلاین به درس‌ها و محتوای ذخیره‌شده - ذخیرهٔ پیشرفت دانش‌آموز روی همان دستگاه - افزودن آیکون برنامه به صفحهٔ اصلی گوشی - استفاده از بخش‌های آموزشی بدون نیاز دائمی به اینترنت گاهی نیاز به اینترنت دارد
